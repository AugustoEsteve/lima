Glossário

HTML:
Linguagem de marcação utilizada para criar páginas web.
CSS:
Linguagem de estilo utilizada para definir estilo e aparência de elementos HTML.
JavaScript:
Linguagem de programação utilizada para adicionar interatividade a páginas web.
